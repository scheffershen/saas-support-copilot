01 · Conceptual

System boundary — where a question goes, and who's allowed to touch what

One FastAPI process, five internal layers, and three kinds of things outside it: a caller, a set of local read-only data sources, and exactly one thing reachable over the open network. Everything the tool registry touches is read-only by construction — there is no write path out of this box.

block-diagram · system-boundary.svg
service boundary safety gate read-only data path internal layer

Grounded in api/main.py, tools/__init__.py, security/. The copilot never calls Loopline's own HTTP API — it reads its docs, source, git history, and database directly, the same access pattern a read-only analyst would have.

02 · Dynamic

One request, timed — a bug question, start to finish

The middleware wraps the entire call, not just the handler — it assigns a request ID before routing even happens and echoes it on the way out whether the response is a 200 or an error. The reactive loop's second LLM call only happens after a real tool round-trip returns.

sequence-diagram · ask-bug-question.svg
agent-loop call LLM round trip tool round trip internal step, no network

Grounded in api/main.py's add_request_id middleware and exception handlers, memory/orchestration.py::ask(), and agent.py::_run_reactive_loop. A usage question that never calls a tool collapses to one LLM round trip instead of two; a destructive command skips the LLM entirely.

03 · Knowledge

Retrieval — from raw Markdown to a cited context block

Indexing happens once, at startup or /ingest. Access control is enforced before ranking, not after — an ineligible chunk is never scored, never almost-returned. Two independent rankings (keyword and vector) are fused, not blended by a single score.

pipeline-diagram · rag-retrieval.svg
RBAC gate BM25 / keyword embeddings / semantic index-build step

Grounded in retrieval/index.py (DocumentIndex, eligible_indices, search_hybrid), retrieval/bm25.py, retrieval/rrf.py, and security/classification.py. The 0.05 similarity floor exists because an unfiltered cosine ranking never returns nothing — it just reorders the whole corpus.

04 · Behavioral

What the agent decides, step by step

Two gates run in code the model never touches, before routing even starts. Everything after that is either a bounded reactive loop with a repeated-call guard and a step ceiling, or a plan-first workflow with its own bounded revision budget — neither can loop forever, and neither can answer a gated domain without real evidence.

flowchart · run_agent.svg
gate / classify tool call success path raised error, mapped to an HTTP status

Grounded in agent.py::run_agent / _run_reactive_loop, security/intent.py, agent_types.py, and planning/feasibility.py. Every error node here is a real Python exception class, not a generic failure state — each maps to one HTTP status in api/main.py.

Honest note — a real model doesn't always take the path its own answer implies. Episode 18's live run against gpt-4o-mini found a case where the answer text claimed a query_graph check that tools_called shows never happened. This flowchart is the code's logic, not a guarantee about what any one model call will choose to do inside it.
