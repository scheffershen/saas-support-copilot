# Getting started with Loopline

Loopline is a lightweight ticketing tool for support teams. This article covers
signing in, the ticket list, and where to find help.

## Roles

- **support_agent** — can view, create, comment on, and be assigned tickets.
- **support_lead** — everything an agent can do, plus reassigning tickets between agents.
- **billing_admin** — can view tickets but cannot change their status or assignee.

See [Roles and permissions](roles-and-permissions.md) for the full breakdown.
